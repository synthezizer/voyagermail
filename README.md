# voyager mail
Every visitor gets a ring from 1-50. When someone sends a message it "beams" it from their ring and the farthest rings get it last! 
https://voyager-mail.anarc.cc

## how do i test it myself?
- open the tab inside of incognito mode
- use the guide above to create a message
- now go to your main browser window and wait for your incognito window's ring message to show up
